Augmented Segmentation Utility

A semi-automatic image annotation tool integrating Meta AI’s Segment Anything Model (SAM) for medical and scientific imaging.

Computer Vision Deep Learning Medical Imaging GUI Software Python
Overview

About the Project

ASU (Augmented Segmentation Utility) is a desktop GUI application that integrates Meta AI’s Segment Anything Model (SAM) for semi-automatic image annotation and segmentation. The tool is designed to accelerate and standardize ground-truth generation for deep learning model training, particularly in medical and scientific imaging workflows.

The application has been demonstrated on MRI brain tumor segmentation, where it significantly reduced annotation time compared to fully manual methods, while maintaining high boundary accuracy.

Capabilities

Key Features

  • SAM model integration with selectable variants (ViT-H and ViT-B) for different speed/accuracy trade-offs
  • Interactive click-based prompting using positive and negative point inputs for refined segmentation control
  • Project-based batch image management with New, Open, and Save Project workflows
  • Multi-class labeling with fully customizable class names for any annotation taxonomy
  • YOLO-format export for direct compatibility with downstream object detection model training
  • CPU / GPU device selection with automatic fallback to CPU for accessibility across hardware
  • Zoom and fit-to-window controls for precise pixel-level annotation work
  • Undo / Redo and Delete annotation controls for an efficient correction workflow
